**🔥 الأهم : Confluence Data Center ينضرب عبر Apache Axis**
CVE-2026-90436 (CVSS 9.8) ثغرة RCE بدون تسجيل دخول في Apache Axis 1.x (منتهي الدعم EOL)، وRapid7 MDR شافت استغلالها ضد Confluence DC عند عميل يوم 13 نوفمبر.. وهي نفسها اللي كانت داخلة في سلسلة N-central
- الحل : رقّوا Confluence لـ 9.2.28، أو عطّلوا Remote API (XML-RPC و SOAP) لو ما تقدرون الحين
- *POC تصوري (مو منشور عندي) : طلب SOAP/XML-RPC مصنوع على endpoints الـ Remote API المكشوفة للإنترنت ← deserialization ← تنفيذ أوامر. راجعوا اللوقات لأي طلبات غريبة عليها*
[Daily_CyberSec](https://x.com/Daily_CyberSec/status/2122511373053694285) · [DFIR_Radar](https://x.com/DFIR_Radar/status/2122429839617806635)
