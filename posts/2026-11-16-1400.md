**🔥 الأهم : React Server Components — CVE-2026-126187 (CVSS 9.5)**
RCE بدون مصادقة في React Server Components (يشمل React 19 و Next.js)، الثغرة في deserialization للـ typed arrays في بروتوكول Flight.. اليوم انتشر خبر عن PoC منشور، و Step Security قالوا معمل قدر يسوي reproduce لـ Flight row smuggling.
- الحل : 19.0.9 / 19.1.10 / 19.2.9 / 19.3.1
- المتصفح فقط مو متأثر، الخطر على السيرفر
*POC (مفاهيمي) : طلب Flight معدّل فيه typed array يكسر الـ parsing ويهرّب row تنفّذ كود على السيرفر.. الاستغلال يحتاج شروط معينة (shared ArrayBuffer).*
