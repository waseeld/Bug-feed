**🔴 الأهم : Puppet Server RCE مستغلة (CVE-2026-115731)**
- CVSS 9.4، و CISA ضافتها لـ KEV يعني فيه استغلال فعلي
- أي client معه agent certificate موقّع من الـ CA يقدر يرسل report مصنوع ويشغّل كود على السيرفر
- الخطورة : سيرفر Puppet هو نفسه الـ CA، يعني اللي يدخله يقدر يطلع هوية لأي host
- الإصلاح : 2026.0.1 و 2025.12.1 و 2023.8.13
*POC (مفاهيمي، ما شفت كود منشور) : agent بشهادة صالحة يرفع report فيه payload deserialization ← تنفيذ كود بصلاحية خدمة Puppet Server*
